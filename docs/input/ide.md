# Ide: KosFinder

## 1. Pengguna
- Mahasiswa atau masyarakat yang sedang mencari tempat kos, khususnya di sekitar kampus.
- Pemilik kos yang ingin mempublikasikan dan mengelola informasi kos miliknya.

## 2. Masalah
- Informasi kos masih tersebar di media sosial, grup WhatsApp, dan informasi dari mulut ke mulut.
- Pencari kos kesulitan membandingkan harga, lokasi, dan fasilitas.
- Pemilik kos kesulitan memperbarui informasi ketersediaan kamar.

## 3. Yang Diharapkan Bisa Dilakukan
- Pencari kos dapat melihat daftar kos.
- Pencari kos dapat mencari kos berdasarkan area.
- Pencari kos dapat menyaring kos berdasarkan harga dan fasilitas.
- Pencari kos dapat melihat detail informasi kos.
- Pemilik kos dapat mendaftar dan login.
- Pemilik kos dapat menambahkan, mengubah, dan menghapus informasi kos miliknya sendiri.

## 4. Batasan
- Aplikasi dibuat menggunakan Flutter untuk Android.
- Backend menggunakan Supabase.
- Pencari kos dapat melihat daftar kos tanpa harus login.
- Pemilik kos harus login untuk mengelola data kos.
- Versi pertama tidak mencakup pembayaran online, fitur chat, ulasan dan rating, rekomendasi AI, verifikasi identitas pemilik, upload foto, dan peta.
